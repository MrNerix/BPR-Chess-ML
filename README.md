# BPR Chess ML (Bachelor’s Project)

A **Machine Learning–based Chess Move Prediction** system developed as part of a **Bachelor’s Project (BPR)**.  
The goal was to train models capable of predicting optimal chess moves and evaluating board states using real game data.

---

## Overview

This project combines **machine learning** and **game theory** to analyze chess gameplay.  
It processes chess data (in PGN/FEN formats), encodes board states, and uses trained models to predict strong moves.  
The project serves as a foundation for exploring **AI-based decision-making** in strategic environments.

---

## Features

- Data preprocessing from large-scale chess game datasets  
- Board state encoding for ML input  
- Model training and evaluation for move prediction  
- Move strength classification and accuracy comparison  
- Visualization of prediction results  
- Modular design for further AI experiments

---

## Technologies Used

| Tool / Library | Purpose |
|----------------|----------|
| **Python 3** | Core development language |
| **TensorFlow / Keras** | Neural network training |
| **NumPy / Pandas** | Data manipulation and preprocessing |
| **python-chess** | Chess game parsing and board state management |
| **Matplotlib** | Result visualization and performance graphs |
| **Jupyter Notebook** | Model training and experimentation |

## Results

- Achieved consistent prediction accuracy across validation datasets.  
- Demonstrated clear improvement over random-move baselines.  
- Provided insight into ML-driven decision-making in strategic games.
